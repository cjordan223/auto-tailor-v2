Security Audit Summary - August 26, 2025

This document summarizes the security changes made to the application and outlines the remaining vulnerabilities.

## Changes Implemented

1.  **Input Sanitization (Critical Vulnerability Fixed):**
    *   **File:** `frontend/server/routes/process.js`
    *   **Change:** Added sanitization to the `jobDescriptionText` input field to strip all HTML tags.
    *   **Reason:** Prevents potential HTML/script injection attacks.

2.  **Rate Limiting (High-Risk Vulnerability Fixed):**
    *   **File:** `frontend/server/index.js`
    *   **Change:** Implemented rate limiting for all API routes (`/api/*`). The server now limits each IP to 100 requests per 15 minutes.
    *   **Reason:** Protects the server from Denial-of-Service (DoS) attacks and resource abuse.

3.  **Dependency Vulnerabilities (Fixed by User):**
    *   **Status:** The 6 previously identified vulnerabilities were resolved by running `npm audit fix --force`.
