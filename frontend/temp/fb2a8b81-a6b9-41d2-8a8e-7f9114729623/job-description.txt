Company: Velocity Games
Position: DevOps Engineer

Job Description:
Velocity Games is an innovative game development studio creating immersive online multiplayer experiences. We're seeking a DevOps Engineer to build and maintain the infrastructure that supports our game servers and development pipelines. In this role, you'll empower our developers to ship code faster and more reliably while ensuring our players have a stable, low-latency gaming experience.

Responsibilities:
* Design, manage, and improve our CI/CD pipelines using tools like GitLab CI, Jenkins, or CircleCI.
* Automate the deployment, scaling, and management of our game server infrastructure on AWS.
* Manage infrastructure as code (IaC) with tools like Terraform and CloudFormation.
* Implement robust monitoring, logging, and alerting solutions (e.g., Prometheus, Grafana, ELK Stack) to ensure system health.
* Work with development teams to containerize applications using Docker and manage them with Kubernetes (EKS).
* Optimize cloud resource usage to manage costs effectively.
* Maintain system security and compliance by implementing best practices and automated checks.
* Support build and release processes, including troubleshooting build failures and deployment issues.

Required Qualifications:
* 3+ years of experience in a DevOps, SRE, or related role.
* Strong experience with a major cloud provider, preferably AWS (EC2, S3, RDS, EKS).
* Proficiency with CI/CD concepts and tools.
* Hands-on experience with containerization (Docker) and orchestration (Kubernetes).
* Experience with infrastructure as code (Terraform preferred).
* Strong scripting skills in Bash, Python, or Go.
* Solid understanding of Linux systems and networking fundamentals.

Desired Qualifications:
* Experience in the gaming industry or supporting high-traffic, low-latency applications.
* Familiarity with database management and scaling (e.g., PostgreSQL, Redis).
* Knowledge of network infrastructure for online gaming (e.g., DDoS mitigation).
* A passion for video games and online communities.
